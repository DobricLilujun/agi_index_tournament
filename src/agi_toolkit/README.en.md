# AGI Tournament Toolkit Design

## Project Goals & Plan

1. Rewrite (the “4R” framework)
   1. Reword: Dictionary-based rewriting; back-translation; LLM rewriting.
   2. Random Rearrange: Randomly shuffle sentences; randomly shuffle words.
   3. Realize: Summarization; agentic debating; “When to stop?”
   4. Recheck: Use an LLM as a judge; compare similarity and correctness; evaluate the similarity between questions generated by the current model vs. the new model.

2. Correctness Evaluation  
   Conduct systematic evaluation and testing for these strategies, including long questions, short questions, and different benchmarks.
   1. Build a unified evaluation framework in code.
   2. Support plugging in various benchmarks for testing.
   3. Test the AGI Index in code.
   4. Implement the full end-to-end pipeline for a single question in code.
   5. Test the combined effects of different rewrite strategies; identify and compare patterns.
   6. Add an ablation test: use a latest human-created benchmark and test it with our pipeline as well, to see how effective rewriting is.
   7. Explore how to successfully confuse the strongest models using the strongest strategy combinations.

3. Diversity Evaluation
   1. Evaluate how different rewrite strategies improve diversity.
   2. Evaluate how different rewrite strategies improve correctness.
   3. Evaluate how different rewrite strategies improve efficiency.
   4. Evaluate how different rewrite strategies improve performance on complex questions.
   5. Evaluate how different rewrite strategies improve performance on long questions.
   6. Evaluate how different rewrite strategies improve performance on short questions.
   7. Evaluate how different rewrite strategies improve performance across questions from different domains.

4. Evaluate the generalization of all models across different capabilities.
   1. Evaluate how different models generalize across different capabilities, using our AGI Index for testing and reporting.
   2. Evaluate how humans generalize across different capabilities, using our AGI Index for testing and reporting.
   3. Use SPoSE modeling to conduct comparative research and testing between the human brain and LLMs, then draw a distribution/capability comparison plot between the brain and the models.
